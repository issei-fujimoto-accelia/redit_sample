# 021 返信フォームの簡略化の実装

元計画：[020](020-docs-reply-form-simplify.md) で更新した UI_GUIDELINES §4.2・§5・§7

## Background

020 の決定に従い、スレッドページの返信フォームから「返信する」の見出しと「本文」の見えるラベルをなくし、プレースホルダー「会話に参加する」を付ける。

## Dependencies

- 020

## Scope

- `Field` に、見えるラベルを隠すオプション（視覚的に隠したラベル）と `placeholder` を追加
- スレッドページの返信フォーム：見出しなし、ラベルを視覚的に隠す、プレースホルダー「会話に参加する」
- 400 の再描画では、エラー文を表示し入力値を保持する（従来どおり）
- スタイルガイドに「ラベルなしの入力」の見本を追加し、セルフチェック（UI_GUIDELINES §9）を行う

## Out of scope

- 返信以外のフォーム（作成・編集）の見た目の変更

## Implementation notes

- テストは CSS クラスに依存させず、表示されるテキストと属性で確認する（TEST_STRATEGY §3.3）。
- axe で、入力欄にアクセシブルな名前があることを確認する。

## Acceptance criteria

- [ ] 返信フォームに「返信する」の見出しと見える「本文」ラベルがなく、プレースホルダー「会話に参加する」がある
- [ ] 入力欄にアクセシブルな名前があり、`npm run design:audit` の違反が0件
- [ ] 返信の投稿・400 の再描画が従来どおり動く
- [ ] 共通 DoD

## Tests（S1：`test/http/posts.test.ts`）

- スレッドページの返信フォームに `placeholder="会話に参加する"` の入力欄がある
- 返信フォームの入力欄にラベル（視覚的に隠したもの）または `aria-label` が付いている
- 既存の返信の作成・400・404 のテストが通る
