# 019 スレッド作成ページとヘッダーの「投稿する」ボタンの実装

元計画：[018](018-docs-thread-create-page-and-post-button.md) で更新した REQUIREMENTS・ARCHITECTURE §5・UI_GUIDELINES §4〜5

## Background

018 の決定に従い、スレッド作成を独立したページにし、全画面のヘッダーに「＋ 投稿する」ボタンを置く。

## Dependencies

- 018
- 017（作成ページの組み方と `scripts/design` の対象画面をそろえるため、017 の後に着手する）

## Scope

- 作成ページ（018 推奨案：`GET /t/new?c=:id`）：コミュニティのプルダウン（名前順、初期値あり）、タイトル、本文
- 送信先（018 推奨案：`POST /t`）：成功時 303 → `/t/:id`、400 は作成ページを入力値・選択値付きで再描画
- `SiteHeader` に「＋ 投稿する」ボタン（インライン SVG の＋アイコン）。`Layout` に現在のコミュニティ ID を渡し、コミュニティページ・スレッドページではリンクに初期値を付ける
- コミュニティページからスレッド作成フォームを外す（空状態の案内は投稿ボタン・作成ページへ誘導）
- 018 の決定に従い `POST /c/:id/threads` を廃止（または存続）し、テストヘルパー `createThread` と `scripts/design/seed.mjs` を新しい送信先に合わせる
- 共通部品 `Select`（`Field` と同じラベル・エラー・`aria-describedby` の仕組み）をスタイルガイドに追加
- セルフチェック（UI_GUIDELINES §9）：全画面のヘッダー、スレッド作成ページ、コミュニティページ

## Out of scope

- 返信フォームの見直し（021）

## Implementation notes

- ルート定義の順序に注意する（`/t/new` を `/t/:id` より先に定義）。
- コミュニティの存在確認はサービス層で行い、存在しない・未選択はフィールドエラー（400）にする。
- `?c=` の不正値は未選択として扱い、エラーにしない。
- モバイルのヘッダーが1段に収まらない場合は、018 で決めた配置（アイコンのみなど）に従う。押せる範囲は 44px。

## Acceptance criteria

- [x] 全画面のヘッダー右上に「＋ 投稿する」があり、スレッド作成ページへ移動する
- [x] コミュニティページ・スレッドページからの投稿ボタンでは、そのコミュニティが初期値になる。それ以外では未選択
- [x] 作成ページでコミュニティを選び、タイトルと本文を入力してスレッドを作成できる
- [x] コミュニティページにスレッド作成フォームがない
- [x] セルフチェックで対象画面が合格し、`design/rounds/NN/review.md` に記録されている
- [x] 共通 DoD

## Tests（S1：`test/http/threads.test.ts` ほか）

- 全画面（ホーム・一覧・コミュニティ・スレッド）のヘッダーに作成ページへのリンクがある
- コミュニティページ・スレッドページの投稿ボタンのリンクに、そのコミュニティ ID の初期値が付く。ホームでは付かない
- `GET /t/new?c=:id` → 200、該当コミュニティが選択済み。`?c=abc`・存在しない ID → 200、未選択
- `POST /t` 成功 → 303 `/t/:id`、選んだコミュニティのスレッドとして一覧に出る
- コミュニティ未選択・存在しないコミュニティ → 400、入力値を保持して再描画
- タイトル空・本文 10,001文字 → 400（既存の代表ケースを新しい送信先に移す）
- コミュニティページにスレッド作成フォーム（送信先）がない
- 既存の一覧・削除・セキュリティのテストが、新しい `createThread` で通る

## 実装メモ

- `GET /t/new`（`?c=` で初期値。不正値は未選択）、`POST /t`（`community_id`・タイトル・本文をまとめて検証し 400 で再描画）。`POST /c/:id/threads` とコミュニティページの作成フォームは削除。
- 検証直後にコミュニティが削除された場合（外部キー違反）も 400 にする。
- `PostButton`（インライン SVG の＋、デスクトップは「＋ 投稿する」、モバイルはアイコンのみ）を `SiteHeader` に追加。`Layout` の `postCommunityId` でリンクの初期値を付ける（コミュニティページ・スレッドページ）。
- 共通部品 `Select` を追加し、スタイルガイドに `Select` と `PostButton` の見本を追加。
- テストヘルパー `createThread` と `design:seed` を `POST /t` に変更。
- コミュニティページのナビの現在地を「上位の現在地」（`aria-current="true"`）にそろえた（作成ページ・スレッドページと同じ扱い）。
- セルフチェック：`design/rounds/17/review.md`（合格）。
