# 009 スレッドの修正・削除（返信なし）とコミュニティ削除の不可条件

元計画：[IMPLEMENTATION_PLAN.md W9](../docs/IMPLEMENTATION_PLAN.md#w9-スレッドの修正と削除返信なしコミュニティ削除の不可条件)

## Background

スレッドの修正・削除と、スレッドを持つコミュニティを削除できないルールを扱う。スレッドが作れるようになったため、006 で後回しにしたコミュニティ削除の 409 をここで検証する。

## Dependencies

- 006、007（008 と並行可）

## Scope

- `POST /t/:id/edit`：タイトルの修正（303 → `/t/:id`）。「編集済み」表示
- `POST /t/:id/delete`：返信のないスレッドを本文ごと削除（303 → `/c/:community_id`）
- スレッドページの編集フォーム（`<details>`）と削除ボタン（`confirm`）。作成者本人にのみ表示
- スレッドがあるコミュニティの削除 → 409、コミュニティページを理由付きで再描画

## Out of scope

- 返信がある場合のスレッド削除不可（012）

## Implementation notes

- スレッド削除の batch：本文を DELETE（返信が存在しない条件付き）→ `threads` を DELETE（投稿が存在しない、かつ本人の条件付き）。ARCHITECTURE §4.4。
- コミュニティの DELETE 文に「スレッドが存在しない」条件を含める。0行のときは原因を判別して 409 にする。
- タイトル修正では `last_posted_at` を変えない。

## Acceptance criteria

- [x] タイトルを修正すると「編集済み」が表示される
- [x] 返信のないスレッドを削除でき、コミュニティページへ移動する
- [x] スレッドがあるコミュニティは削除できず、理由が表示される。コミュニティもスレッドも残る
- [x] 他人には操作が表示されず、直接 POST しても 403 でデータは変わらない
- [x] 共通 DoD

## Tests（S1：`threads.test.ts`、`communities.test.ts`、`security.test.ts`）

- タイトル修正 → 303、新しいタイトルと「編集済み」が表示される。作成直後は「編集済み」が出ない
- タイトルを空に修正 → 400
- 返信なしのスレッドを削除 → 303 `/c/:community_id`、`/t/:id` が 404、一覧から消える
- スレッドがあるコミュニティの削除 → 409、理由の表示、その後の GET でコミュニティとスレッドが残っている
- 他人でスレッドページを GET → 修正・削除の操作が表示されない
- 他人のスレッドの修正・削除 POST → 403、内容が変わっていない

## 実装メモ

- スレッド削除の batch：本文の DELETE（返信なし かつ 本人のスレッド）→ `threads` の DELETE（投稿なし かつ 本人）。0行なら原因を判別し、返信ありは 409（テストは 012）。
- コミュニティ削除の 409 は 006 で実装済みの条件付き DELETE をそのまま使い、ここでテストを追加した。
