# 013 ホームの横断スレッド一覧

元計画：[IMPLEMENTATION_PLAN.md W13](../docs/IMPLEMENTATION_PLAN.md#w13-ホームの横断スレッド一覧)

## Background

「発見」の体験を担う、全コミュニティ横断のスレッド一覧を実装する。投稿の作成・修正・削除による並び順の変化（ADR-3 の派生値）を、ホームで総合的に検証する。

## Dependencies

- 011（012 と並行可）

## Scope

- `GET /` のスレッド一覧：`communities` を JOIN、`last_posted_at DESC, id DESC`、1ページ20件、`?page=N`
- 各行：タイトル、コミュニティ名、作成者、投稿数、最終投稿日時
- 001 の仮ホームを置き換える

## Out of scope

- ユーザーごとの出し分け（非スコープ）

## Implementation notes

- 008 と同じ並び順・ページングの規則を使う。クエリ側の共通化はレビュー段階で判断する。
- 表示は 008 と同じ `ThreadList`・`ThreadListItem`（コミュニティチップあり）を使う。ホームはコンセプト上もっとも編集的に組む画面（UI_GUIDELINES §4.2）。
- 全体件数・並び順に依存するため、テストは `listing-home.test.ts` に分ける（TEST_STRATEGY §3.1）。

## Acceptance criteria

- [ ] 全コミュニティのスレッドが横断で表示され、各行にコミュニティ名が出る
- [ ] 最終投稿日時の新しい順。古いスレッドに返信すると先頭に移動する
- [ ] 最新の返信を削除すると、並び順が元に戻る
- [ ] 投稿の修正では並び順が変わらない
- [ ] 21件以上で20件ずつのページに分かれる
- [ ] 共通 DoD

## Tests（S1：`test/http/listing-home.test.ts`）

- 2つのコミュニティのスレッドが両方表示され、各行に正しいコミュニティ名
- 時計で時刻を決めた3件が新しい順。最も古いスレッドに返信すると先頭へ
- その返信を削除すると、元の順に戻る
- 投稿を修正しても順序が変わらない
- 21件 → 1ページ目20件、2ページ目1件
