# Round 17 — スレッド作成ページとヘッダーの投稿ボタン（019）

## スクリーンショット
- 全画面 × 4 条件（thread-new / thread-new-preset を追加）。360px のヘッダーを別途確認

## 採点
| 軸 | 点 | 根拠 |
|---|---|---|
| A. ビジュアル | 8 | 投稿ボタンはヘッダーで唯一の塗りの要素で、主要操作がひと目でわかる |
| B. 独自性 | 8 | 初期値のコミュニティがあると作成ページの見出しがその色相になり、投稿先を色でも示す |
| C. 構造 | 8 | 全画面から作成ページへ。コミュニティページ・スレッドページからは投稿先が選択済み。キャンセルで元の場所へ戻る |
| D. インタラクション | 8 | ＋アイコンはホバーで回転。プルダウンは JS なしで、初期値はサーバー側の `selected` |
| E. コンテンツ表現 | 8 | コミュニティ0件では作成ページでコミュニティ作成へ誘導。長い表示名はモバイルで省略 |
| F. アクセシビリティ | 9 | axe: 0 件。アイコンのみのボタンに `aria-label="投稿する"`、44px |
| G. 技術品質 | 9 | CSS 38.7 KB / Font 65.7 KB。アイコンはインライン SVG |

## 改善点（このラウンドで対応）
1. 390px でヘッダーが2段になったため、余白・字間を詰め、表示名を省略可能にして1段に収めた
2. 360px でナビのリンクが折り返したため、24rem 以下でさらに詰めた

## 判定
合格
